# Angrybird Hoodbutt

Angry Birds–style game with Hoodbutt characters.

## Features
- Privy email login (same App ID as Robin's Arena)
- Leaderboard
- 10+ levels + infinite procedural levels
- 7 unlockable characters (transparent PNG)
- Background music (toggle with ♪)
- English UI

## Deploy
This folder is ready for **GitHub Pages** — `index.html` is the entry point.

Open the site → click **♪** to start music → **Sign in** with email OTP.
